# Curriculum map

Mastery of a skill level needs three records: the mapped challenge completed, one transfer problem from the practice generators (a context outside that machine), and one recall problem passed on a later day. The workshop queues recall one day after the transfer. Age does not open or lock a challenge.

Strands already in the catalog keep their skills. The eight strands added for this workshop each have one skill and five levels. Later machines should add skills inside those strands. Empty strands are not used, because an empty strand would count as mastered.

## Skills and the challenges that use them

| Skill | Strand | Challenges | Gap |
| --- | --- | --- | --- |
| tens-and-ones | place-value | bridge-count-1 gap 4, bridge-count-2 gap 6, bridge-count-3 gap 5 | Counting only. Place value itself is not required. |
| multiply-facts-2-to-5 | multiplication | bridge-load 12, 8, 15; bridge-depth spans 4, 5, 6; lever balance and two-lever; gear turns, compound, torque, hour 12:1 | The cube law and compound ratios are tagged here because no power or ratio-of-ratios skill exists yet. |
| gap-between-marks | measurement-and-units | bridge-units lengths 5, 7, 6 from gaps 4, 6, 5 plus 0.5 m bearings | Half meters are typed in the workshop. The generator is still whole numbers. |
| subtract-no-borrow-two-digit | addition-subtraction | bridge-pier positions 2, 2.5, 3 | Halving is not subtraction. Marked for a later measurement skill. |
| rectangle-area | geometry | bridge-truss loads 12, 8, 16, one diagonal | Weak map. Member force is not area. |
| ratio-shares | ratios-and-proportion | bridge-arch rises 3; lever classes 1, 2, 3; gear ratios 4:1, 3:1, 5:1 | Serves ratio. Trigonometry of the arch is not here. |
| line-from-the-origin | functions-and-graphs | bridge-cable hangers 3, 1.5, 4 | Weak map. The cable is a parabola, not a line through the origin. |
| missing-addend | algebra | lever-mass answers 6, 8, 5 | Weak map. The unknown is a product, not an addend. |
| compare-numbers | addition-subtraction | gear-way idler counts 1, 0, 1 | Weak map. Direction parity is not comparison. |
| multiply-by-ten-or-hundred | multiplication | gear-clock 60:1 and both-hands 60:1 | The 12:1 hour train is a separate predict on gear-clock-3 and is not graded by the model. |

## Skills with no machine challenge yet

These stay in the graph for placement and practice. No bridge, lever, or gear challenge opens them:

- The rest of place-value, addition-subtraction, and multiplication beyond the ids above.
- unit-fraction-of-a-whole
- mean-of-three
- right-triangle-hypotenuse

Later machines named in the plan (pulley crane, bicycle drivetrain, tower crane, ramps and coaster, trebuchet, go-kart, robot arm) should take the unmarked skills, and should replace the weak maps above with skills that match the operation.
