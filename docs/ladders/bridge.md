# bridge ladder

## Level 1: Count the sticks

Job: Cross the gap. Output: wagon.

Count the sticks that carry a 20 kg wagon across the gap.

Dials: numbers 0, representation 0, given 0, freedom 0, precision 0.

- A 4 block gap. Measure 4. Part 4. Predict 4. Output wagon.
- A 5 block gap. Measure 5. Part 5. Predict 5. Output wagon.
- A 6 block gap. Measure 6. Part 6. Predict 6. Output wagon.
