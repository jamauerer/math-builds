# Plank width

Deck planks are named by width, the amount of gap they cover. Length is the longest side, side to side.

- `word-problem.png` — Word problem: each plank is 1 ft wide. The picture marks that size along the gap and labels it width.
- `tray-labels.png` — Kit tray with the plank stamp "1 ft wide".
