# Learning system

Pre-reader questions are spoken. Level 1 uses drag and tap. Level 2 uses a 0 to 10 numeral strip. Skills move through New, Learning, Practicing, Fluent, and Mastered. Review comes back by forgetting.

- `drag-count.png` — a level 1 count-by-dragging question, no keypad, with a Hear it button.
- `numeral-strip.png` — a level 2 question answered on the 0 to 10 numeral strip, with dots under each number.
- `parent-fluent.png` — the parent view showing Longer or shorter in the Fluent state and its median time trend.
- `warmup-review.png` — the warm-up card marked Review for a skill that is due.
